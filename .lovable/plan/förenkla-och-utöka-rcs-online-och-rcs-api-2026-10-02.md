# Förenkla och utöka RCS Online och RCS API

## Mål
Efterlikna innehållsstrukturen på de två referenssidorna utan att kopiera deras varumärke eller göra sidorna tekniskt tunga. Behåll RCS Direkts luftiga blå/vita designspråk och svenska tonalitet.

## RCS Online
- Tydligare introduktion med två enkla vägar vidare.
- Lägg till en översikt över webbgränssnittets viktigaste delar: skapa utskick, kampanjer, inkorg, kontakter, mallar och statistik.
- Förklara schemaläggning, tvåvägskonversationer och uppföljning i korta, lättskannade block.
- Avsluta med en enkel CTA och länk till API-sidan.

## RCS API
- Tydligare introduktion för integration i egna system.
- Lägg till en enkel översikt över meddelandetyper, knappar, massutskick, personanpassning, schemaläggning och webhooks.
- Visa ett kort, neutralt kodexempel som illustrerar upplägget utan att påstå att ett färdigt API redan är live.
- Förklara testmiljö och autentisering som kommande/erbjudna delar utan att länka till SendRCS.
- Avsluta med en enkel CTA och länk till webbgränssnittet.

## Design
- Återanvänd befintlig sidhuvud, sidfot, typografi, knappar och färgtokens.
- Bygg luftiga sektioner, enkla ikonrader och diskreta ljusblå ytor i stället för att kopiera referenssidornas layout exakt.
- Säkerställ bra läsbarhet på mobil och dator.

## Avgränsning
- Ingen faktisk inloggning, API-nyckel, sandbox eller utskicksfunktion byggs nu.
- Inga påståenden om funktioner som ännu inte är anslutna formuleras som redan tillgängliga.
