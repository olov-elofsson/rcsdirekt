# Brand Context

Läses av brand-skillsen i `.claude/skills/` (till exempel `brand-identity`). Uppgifterna kommer från sajten, CMS:et och AGENTS.md. Rader märkta **Att fylla i** saknar underlag och ska fyllas i av rcsdirekt.se, inte gissas.

## Brand
- **Name**: rcsdirekt.se (en tjänst från WIGOSE AB, Örebro)
- **Category**: Företagsmeddelanden, RCS (Rich Communication Services) för svenska företag
- **Description**: Skicka RCS-meddelanden med bilder, knappar och verifierad avsändare, från webben eller via API, och betala per meddelande.
- **Stage**: Tidig: sajt, kundportal och de första kundcasen (DreamCare, Maptun, Nercia, Bilia). Försäljning i Sverige.
- **Website**: https://rcsdirekt.se

## Audience
- **Primary Audience**: Svenska företag som i dag skickar sms till sina kunder: omsorg, verkstäder och bilhandel, utbildning och e-handel. Både de som vill skicka från webben och de som kopplar egna system via API.
- **Key Problem**: Sms ger ett nummer som avsändare, ren text och förkortade länkar som kunderna inte litar på. Kunden kan inte svara med ett tryck.
- **Their Language**: **Att fylla i** (citat från kundsamtal, mejl eller recensioner)

## Positioning
- **Differentiation**: Enkelt att komma igång, svenska och raka besked, betalning per meddelande utan månadsavgift eller bindningstid, och samma pris från webben som via API.
- **Competitors**: **Att fylla i**
- **Market Position**: Tillgänglig och rak för små och medelstora företag, med volympris för större.

## Brand Personality
- **Personality Words**: enkel, rak, mänsklig, kunnig, lugn
- **Tone**: Avslappnad men saklig. Inga säljord, inga obelagda siffror (se AGENTS.md och `humanizer`).
- **Voice Admires**: 46elks (luftig, rak produktberättelse), Attentive (bilder och levande exempel)
