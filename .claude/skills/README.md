# Skills i repot

Tolv skills, var och en med en uppgift på rcsdirekt.se. AGENTS.md säger när de ska användas.

## Egna

| Skill | Används till |
| --- | --- |
| `rcsdirekt-design` | Designsystemet: hur sajten ser ut och hur något nytt görs i samma stil, även utanför sajten |
| `rcs-phone` | Alla telefoner som visar RCS-meddelanden |
| `make-interfaces-feel-better` | Radier, linjering, skuggor, typografi, ikoner, övergångar |
| `emil-design-eng` | Animationer, easing, tryck- och hovertillstånd |

## Från andra

Kopierade oförändrade från upphovspersonernas repon den 21 november 2026. Varje mapp har sin licensfil. Uppdatera genom att hämta repot på nytt och kopiera över mappen. De kan nämna andra skills från samma bibliotek; de finns inte här.

Svenska regler gäller före skillsens amerikanska råd, till exempel marknadsföringslagen, GDPR och reglerna för reklam via SMS och RCS. Brandkitet och AGENTS.md går före skillsens allmänna råd.
